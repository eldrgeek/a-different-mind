    ▶ HOW IT WORKS

    If it's Mike or another human, they're using a speech-to-text app, so you don't have to sit around waiting for someone to type. (You might still wait while they think of an answer. Or go to the potty.) If it's an AI, it's generating the text directly, because that's what these kinds of AIs do.

    Whoever generates the text, it goes through another app that can read it out loud — if you like.

    And if you want, you can talk back instead of typing, so it feels like you're talking to someone. Even if you think you're not. (An AI isn't someone? It's something? Whatever you say.)

    One straight answer, because this whole page is premised on not playing games with you: as of today it is always an AI. The human-takeover path isn't built yet. When it is, you won't be told which one you got — that's the part Mike actually finds interesting.
